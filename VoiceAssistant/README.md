# Voice Assistant

## 📌 Description

This project is a simple Python-based Voice Assistant developed as part of the Oasis Infobyte Internship Program.

The voice assistant accepts voice commands from the user, processes them, and performs basic tasks.

## 🚀 Features

- Accepts voice commands
- Converts speech into text
- Responds using voice
- Performs basic tasks
- Provides an interactive voice-based experience

## 🛠️ Technologies Used

- Python
- Speech Recognition
- Text-to-Speech

## ▶️ How to Run

Open the terminal in the VoiceAssistant folder and run:

```bash
python voice_assistant.py
