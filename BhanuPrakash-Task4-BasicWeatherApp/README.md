# 🌤️ Basic Weather App

A simple *Weather Application* built using Python that fetches real-time weather information for a city using the *OpenWeatherMap API*.

## 📌 Task 4

This project was developed as part of the *Oasis Infobyte Internship – Python Programming Tasks*.

## ✨ Features

- 🌍 Enter any city name
- 🌡️ Displays current temperature
- ☁️ Displays weather condition
- 💧 Displays humidity
- 💨 Displays wind speed
- 📊 Fetches real-time weather data using an API
- ⚠️ Handles invalid city names and API errors
- 🖥️ Simple and easy-to-use interface

## 🛠️ Technologies Used

- Python
- Requests Library
- OpenWeatherMap API
