# BMI Calculator

## 📌 Description

This is a simple BMI (Body Mass Index) Calculator developed using Python.

The program takes the user's weight and height as input, calculates the BMI, and displays the corresponding BMI category.

## 🚀 Features

- Takes weight as input
- Takes height as input
- Calculates BMI
- Displays the BMI value
- Displays the BMI category

## 🛠️ Technologies Used

- Python

## 📊 BMI Categories

| BMI Range | Category |
|-----------|----------|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal |
| 25 - 29.9 | Overweight |
| 30 and above | Obese |

Open the terminal in the BMICalculator folder and run:
